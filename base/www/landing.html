户用光伏 · 运维管理

光服宝

面向户用与分布式光伏电站的运维管理平台，连接业主、维修方与平台运营三方，覆盖从建档报修到验收结算的完整业务链路。

运维 Agent

电站档案与历史工单沉淀为本地知识库，运维 Agent 在一体机内完成故障初判并给出处理建议，推理过程不依赖外网。

按角色分发的协同入口

业主与维修人员共用同一应用，系统按角色分发任务与视图；运营侧在管理后台统一调度与结算。

运维数据本地留存

电站档案与历史工单存储在本机，支撑故障模式的积累与分析，可在完全离网的环境中运行。

算电互联 · 绿电智算

绿电智算

在光伏电站与园区侧就近部署多台一体机，组成园区算力网：将消纳受限的绿电转换为本地计算能力，并聚合为可调节负荷参与电力平衡。

调度 Agent

多台一体机组成园区算力网，由调度 Agent 依据发电预测与电价信号聚合调节算力负载，作为可调节负荷参与电力平衡。

数据不出厂区

现场图像与运行数据在本地完成推理，仅元数据上行至 Edge 平台，合规边界清晰。

多站点统一纳管

分散的现场设备由 Edge 平台统一管理，站点扩容不线性增加运维人力投入。

长时储能 · 电氢微网

光衡绿盾

面向电氢综合能源系统的智能管控平台：光伏、储能与可逆固体氧化物电池（RSOC）在同一调度引擎下运行，生成日内逐时功率计划并核算购电成本。

管控 Agent

管控 Agent 在一体机上持续求解电解与发电窗口，管理电氢单元的充放电，就地响应工况变化，不受网络时延影响。

同源一致的指标体系

功率、SOC、储氢量、温度与压力由同一仿真引擎推导，各视图的指标口径保持一致。

大学教育 · 产学研平台

产学研项目管理平台

部署在校园机房的私有算力与项目管理底座，支撑课题立项、过程管理与成果转化，为校内团队与企业命题方提供同一份数据基础。

项目 Agent

由项目 Agent 承担立项跟踪、节点提醒与交付物归集，构建以 Agent 为核心的 AI 原生协作方式；模型与项目数据均运行在校内私有算力上。

生产级运行环境

为师生提供可实际部署的算力与平台，支撑从原型开发到上线演示的完整链路。

校企共享数据视图

企业命题、项目进展与阶段成果对校内团队与企业方同步可见，降低沟通与对接成本。

面向城市级充电网络的运营管理平台，由一台一体机承载全市多个县区的站点运营，覆盖订单计费与设备运维。项目在建。

运营 Agent

订单、计费与设备状态的处理在一体机内完成，输出巡检排班与收益报表，站点数据保留在本地。

多站点统一纳管

分布在多个县区的站点由同一台一体机与 Edge 平台统一管理，站点扩容不线性增加运营人力投入。
