# CI/CD

**目的**：在 Portainer（dind-platform 环境）部署 Gitea Actions Runner，实现代码 push → 自动构建 → 推送镜像的完整流水线。全程通过网页操作，无需 SSH。

## 整体流程

```
git push → Gitea(:3100)
              ↓ 触发 Actions
         act_runner (dind内)
              ├─ docker build (dind隔离)
              ├─ docker push → Registry(:5000)
              └─ SSH 10.8.0.8 → docker compose up -d
                                      ↓
                                 服务更新完成
                                      ↓
                              Grafana(:3000) 可观测

```

## 前置（管理员 SSH 执行一次）

SSH 密钥已由管理员生成并配置，Runner 可直接使用：

```
/root/edge/runner/
├── ssh/deploy_key     部署私钥（Runner 挂载用）
└── ssh/deploy_key.pub 公钥（已写入宿主 authorized_keys）
```

## 第一步：获取 Runner Token

1. 打开 `http://10.8.0.8:3100`，用管理员账号登录
2. 右上角头像 → **Site Administration**
3. 左侧 **Actions** → **Runners**
4. 点击右上角 **Create new Runner**
5. 复制页面显示的 Token（仅显示一次）

## 第二步：在 Portainer 部署 Runner

1. 打开 `https://10.8.0.8:9443`，用 admin 登录
2. 顶部环境确认选择 **dind-platform**
3. 左侧 **Stacks** → 右上角 **+ Add stack**
4. Name 填 `runner`，Build method 选 **Web editor**
5. 将以下内容粘贴到编辑框：

```yaml
name: runner

services:
  act_runner:
    image: gitea/act_runner:latest
    container_name: cicd-runner
    restart: unless-stopped
    environment:
      GITEA_INSTANCE_URL: "http://10.8.0.8:3100"
      GITEA_RUNNER_REGISTRATION_TOKEN: "<粘贴第一步复制的 Token>"
      GITEA_RUNNER_NAME: "dind-runner"
      GITEA_RUNNER_LABELS: "dind,linux,docker"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - runner_data:/data
      - /root/edge/runner/ssh:/root/.ssh:ro

volumes:
  runner_data:
    name: cicd_runner_data
```

6. **将 `<粘贴第一步复制的 Token>` 替换为实际 Token**
7. 滚动到底部，点 **Deploy the stack**
8. 等待 10–20 秒（首次拉取 gitea/act_runner 镜像）

## 第三步：确认 Runner 已注册

- 打开 `http://10.8.0.8:3100` → Site Administration → Actions → **Runners**
- 应看到 `dind-runner` 状态为 **Online** 🟢

## 在仓库中使用流水线

将以下文件放到项目仓库的 `.gitea/workflows/` 目录，push 后自动触发：

```yaml
# .gitea/workflows/build.yml
name: Build & Push

on:
  push:
    branches: [main, master]

jobs:
  build:
    runs-on: dind
    steps:
      - uses: actions/checkout@v4

      - name: Build image
        run: |
          docker build -t 10.8.0.8:5000/${{ gitea.repository }}:latest .

      - name: Push image
        run: |
          docker push 10.8.0.8:5000/${{ gitea.repository }}:latest
```

> **镜像仓库**：推送后可在 `http://10.8.0.8:5100` 查看镜像列表
