# Hub — AI 资源枢纽

接入与管控层：本地推理服务、免费额度、付费 API 统一池化为「渠道」，对外只暴露一个 OpenAI 兼容端点。

## 版本


| 组件       | 镜像                              |
| ---------- | --------------------------------- |
| new-api    | `calciumion/new-api:v1.0.0-rc.25` |
| PostgreSQL | `postgres:16.15-alpine`           |
| Redis      | `redis:7.4-alpine`                |

固定版本，不用 `latest`。

## 地址与端口


| 服务       | 地址                    | 说明                      |
| ---------- | ----------------------- | ------------------------- |
| new-api    | `http://<宿主IP>:18080` | 控制台 + OpenAI 端点`/v1` |
| PostgreSQL | `127.0.0.1:5434`        | 库`newapi`，账号见 `.env` |
| Redis      | `127.0.0.1:6379`        | 无密码                    |

全部 `network_mode: host`，容器端口即宿主端口。5432/5433 已被 `stacks/port-forward` 占用，故 PG 走 **5434**。

## 命令

```bash
cd /root/edge/hub

docker compose up -d              # 启动
docker compose ps                 # 状态
docker compose logs -f new-api    # 日志
docker compose down               # 停止（数据卷保留）
```

首次访问 `http://<宿主IP>:18080` 引导创建管理员账号。

## 渠道池

```text
客户端
   │  令牌 sk-xxx（绑定分组）
   ▼
new-api (:18080)
   ├─ 本地 vLLM          优先级 10  分组 local
   ├─ 免费额度池（多 Key） 优先级 5   分组 free   倍率 0
   └─ 付费 API 兜底       优先级 1   分组 local,free
```


| 渠道            | Base URL                              | 关键配置                                                                                 |
| --------------- | ------------------------------------- | ---------------------------------------------------------------------------------------- |
| 本地 vLLM       | `http://127.0.0.1:18000/v1`           | 类型 OpenAI；密钥任意占位；模型须与`--served-model-name` 一致；优先级 `10`；分组 `local` |
| NVIDIA 免费额度 | `https://integrate.api.nvidia.com/v1` | 类型 OpenAI；**多 Key 模式**（单账号约 40 RPM）；优先级 `5`；分组 `free`；倍率 `0`       |
| 付费 API 兜底   | 按供应商                              | 优先级`1`；分组 `local,free`                                                             |

分组决定可用渠道与计费：`local` 日常自用、`free` 内测与低优先任务，两者均兜底到付费渠道。

## 配置纪律

- **分组内渠道类型保持纯净**：选渠道只按「分组 + 模型名」过滤，不按协议类型；混入异类型会触发有损协议转换。本地 vLLM 与 NVIDIA 同属 OpenAI 协议族，可安全同组。
- **多 Key 是免费额度池的刚需**：单账号直连必被限流；开启「自动禁用」令失效账号自动下线。
- **切换 vLLM profile 后**同步更新渠道模型勾选，模型名须与启动参数一致。

## 令牌

用户注册后在「令牌」页自助创建 `sk-xxx`，可设额度上限 / 模型白名单 / 过期时间 / IP 白名单 / 绑定分组。管理员在「用户管理」分配角色与配额；`sk-{token}-{channelId}` 可强制指定渠道，仅排错用。

## 注意

- **`.env` 不入库**：含数据库密码与会话密钥；`SESSION_SECRET` 改值后所有用户需重新登录。
- **许可证**：new-api 为 AGPLv3 + 附加条款，内部自用无碍；对外提供修改版网络服务需履行开源义务。
